# Strategy Data

`journeyData.ts` is the stable re-export barrel. Add or update data in the module that owns the subject:

- `types.ts` defines shared audience, persona, journey, and measure types.
- `audiences.ts` owns audience summaries, personas, and the 10–20% LGBTQ+ strategic focus.
- `journeys.ts` owns audience and persona stage journeys.
- `experience.ts` owns touchpoints, service blueprint, emotional moments, and opportunities.
- `measurement.ts` owns growth signals.
- `research.ts` owns learning paths, source notes, and references.

The source strategy documents in `docs/` — `Kathai_Gen_Alpha_Customer_Journey_Map.docx` and `Kathai_Premium_Consumer_Journey_Experience_Led_V2 1.docx` — are the primary user-supplied strategy references. Keep Aarav’s child-interest/parent-purchase roles distinct. Keep LGBTQ+ safety, belonging, community, and destination choice visible across General Premium and Gen Z.
